## Fresh checks (as Lalo)

- **His class days.** The four days hold his class structure, and the Saturday WOD class is optional:
  - Monday: squat + double-unders.
  - Tuesday: press + snatch.
  - Thursday: deadlift + toes-to-bar.
  - Friday: clean + pull, with the lunge.
  - Each day runs core first, then skill or power, then strength, accessories and the WOD.
- **The named workouts.** Each prints the community standard, the scaled version and the right note (Hero: "pace it; split the reps"). Diane returns in the test week as a retest. This is the community feel he asked for.
- **H11.** Wall balls are 14-20 lb, "never over 20 lb"; medball slams are light. No medball in main lifting.
- **H09.** "Nothing in the WOD counts as muscle sets" is on every WOD, and the weekly table counts lifting only.
- **Reps.** Big lifts follow his class ladder (7 → 5 reps) and small muscles run 10-12.
